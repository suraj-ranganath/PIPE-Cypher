# PIPE-Cypher arXiv Source

This directory contains the arXiv version of the PIPE-Cypher paper.

Compile from this directory with:

```bash
latexmk -pdf -interaction=nonstopmode main_arxiv.tex
```

The public code repository is:

```text
https://github.com/suraj-ranganath/PIPE-Cypher/
```

The public benchmark exports are:

```text
https://huggingface.co/datasets/suraj-ranganath/PIPE-Cypher-benchmarks
```
